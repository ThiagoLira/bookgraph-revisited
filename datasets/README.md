# Datasets

This directory contains the core datasets used by the BookGraph pipeline.

## Files

### Goodreads Data

*   **`books_index.db`** (20 GB): SQLite database with FTS5 full-text search index for ~2.4M Goodreads books.
    *   **Built by**: `scripts/build_goodreads_index.py`
    *   **Source**: `goodreads_books.json` + `goodreads_book_authors.json`
    *   **Tables**:
        - `books_fts` — FTS5 virtual table (title, authors, book_id, data JSON)
        - `books` — Regular table (book_id, data JSON, original_publication_year)
        - `publication_dates` — Enrichment cache (book_id PK, year, source). Synced from `original_publication_dates.json` and updated by `MetadataEnricher.save()` after each pipeline run.
    *   **Read by**: `SQLiteGoodreadsCatalog`, `MetadataEnricher`

*   **`goodreads_books.json`** (9.2 GB): Raw Goodreads book catalog, JSON lines format.
    *   **Source**: UCSD Book Graph dataset.
    *   **Note**: Source for `books_index.db`. Not read at runtime.

*   **`goodreads_books.parquet`** (2.3 GB): Parquet format of the same catalog, for fast analytical queries.

*   **`goodreads_book_authors.json`** (105 MB): JSON lines, maps author_id → name, ratings, works_count.
    *   **Source**: UCSD Book Graph dataset.
    *   **Read by**: `GoodreadsAuthorCatalog` (loaded once, class-level cache).

### Author & Enrichment Data

*   **`author_aliases.json`** (42 KB): Hand-curated mapping of canonical author names to variant spellings.
    *   **Format**: `{"Canonical Name": ["Variant 1", "Variant 2", ...]}`
    *   **Read by**: `AuthorAliasRegistry`, `DeterministicQueryGenerator`

*   **`authors_metadata.json`** (725 KB): Enriched author biographical metadata. **Grows with each pipeline run.**
    *   **Format**: `{"Author Name": {"birth_year": int, "death_year": int, "main_genre": str, "nationality": str, "canonical_name": str?}}`
    *   **Generated by**: `MetadataEnricher` (4-source cascade: cache → local wiki DB → Wikipedia web → LLM)
    *   **Read by**: `MetadataEnricher` (startup cache)
    *   **Written by**: `MetadataEnricher.save()` (also syncs to `author_overrides` table in wiki DB)

*   **`original_publication_dates.json`** (71 KB): Mapping of Goodreads book_id → original publication year. **Grows with each pipeline run.**
    *   **Problem solved**: Raw Goodreads data often contains edition year (e.g., 2003 reprint) instead of original year (1914). This file stores the true original year.
    *   **Generated by**: `MetadataEnricher` (cascade: cache → Goodreads scraper → Wikipedia → LLM)
    *   **Read by**: `MetadataEnricher` (startup cache)
    *   **Written by**: `MetadataEnricher.save()` (also syncs to `publication_dates` table in books DB)

### Wikipedia Data

*   **`wiki_people_index.db`** (2.7 GB): SQLite database with FTS5 index of Wikipedia people pages.
    *   **Built by**: `scripts/build_wiki_people_index.py` (from `people_pages.jsonl` filtered from Wikipedia dump)
    *   **Tables**:
        - `people_fts` — FTS5 virtual table (title, data JSON with page_id, infoboxes, categories, birth/death years)
        - `author_overrides` — Birth/death year overrides and biographical metadata (name PK, birth_year, death_year, main_genre, nationality, canonical_name). Synced from `authors_metadata.json` and updated by `MetadataEnricher.save()`.
    *   **Read by**: `SQLiteWikiPeopleIndex`

## Data Flow

```
Pipeline Run
  ├── reads from JSON + SQL at startup
  ├── resolves citations (Goodreads FTS + Wikipedia FTS)
  ├── enriches missing metadata (scraper / web / LLM)
  └── enricher.save() writes back to:
      ├── original_publication_dates.json  (JSON)
      ├── publication_dates table           (SQL in books_index.db)
      ├── authors_metadata.json             (JSON)
      └── author_overrides table            (SQL in wiki_people_index.db)
```

Each pipeline run enriches the datasets, making subsequent runs faster (more cache hits).

## Usage

These files are expected to be in `datasets/` relative to the project root. The path is configurable via `PipelineConfig` but defaults to this location.
